# Kickstart

**Trainingsteil:** auffangen · **Kategorien:** G, F

## Aufbau

Sechs oder mehr Minitore stehen verteilt auf dem Platz, bevor das Training beginnt. Jedes Kind, das eintrifft, schnappt sich einen Ball und schiesst — mal auf dieses Tor, mal auf jenes, oder es zieht selbständig eine Runde von Tor zu Tor.
